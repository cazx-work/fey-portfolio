# Felix Edrian Ybañez — Engineering Portfolio

A documentation-inspired personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, typed local content, Vitest, and Playwright.

## Start locally

```text
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validate

```text
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

The source material remains in `docs/contents` and is never modified by the site. The internal inventory and factual context are in `docs/source-content-inventory.md` and `docs/portfolio-context.md`.

## Content policy

The site uses approved public-safe claims and avoids unsupported metrics, confidential implementation details, and unapproved professional links. Approved contact information and remaining publishing questions are tracked in `docs/content-questions.md`.
