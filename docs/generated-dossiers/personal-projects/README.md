# Personal Projects

Use this directory for personal projects written with the same standard as the SEPIA dossiers: specific, evidence-based, and non-generic.

Each project should begin with frontmatter:

```yaml
---
type: personal-project
slug: project-slug
title: Project title
project: Personal
visibility: public
status: published
featured: false
tags: TypeScript, Design
---
```

Then include `## Executive Content` and `## Technical Deep-Dive`.

Writing rules:

- Lead with the real system problem, not a technology list.
- Keep ownership language accurate (contributed vs owned).
- Explain failure paths and tradeoffs, not only happy paths.
- Avoid unsupported metrics and unverifiable impact claims.
