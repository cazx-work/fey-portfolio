# Capabilities Content Dossier

This dossier presents transferable engineering capabilities drawn from SEPIA work, written to avoid generic claims and repetitive template language.

Each capability page does two jobs:

- Executive Content: concise value and boundary clarity.
- Technical Deep-Dive: ownership model, failure patterns, tradeoffs, and evidence strategy.

The writing standard is evidence-first:

- Claims are grounded in approved source material.
- Collaborative contribution is described accurately.
- Metrics are omitted unless explicitly supported.
- Proprietary implementation detail remains generalized.
