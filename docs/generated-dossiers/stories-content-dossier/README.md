# Engineering Stories Dossier

These stories are rewritten as concrete engineering investigations, not generic templates.

Each story keeps the same two-layer format:

- Executive Content: what changed and why it mattered.
- Technical Deep-Dive: boundary model, failure paths, tradeoffs, and evidence.

The content is grounded in approved SEPIA material and journal themes, with explicit limits:

- No unsupported metrics.
- No inflated ownership claims.
- No publication of proprietary implementation details.
