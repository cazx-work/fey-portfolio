## Navigation rules

- Keep the left navigation to six top-level branches.
- Use `portfolio-v3.md` as the primary narrative page.
- Put implementation inventories, interview prompts, and edge-case catalogs behind expandable panels.
- Attach evidence to the story it proves rather than creating a screenshot gallery as the main experience.
- Keep technical deep dives available without requiring recruiters to read them.
